# StudentSpace 🚀

An independent, community-driven web platform designed to help Nigerian university applicants seamlessly check admission eligibility, calculate aggregate scores, and navigate the transition to tertiary education.

🔗 **Live URL:** [studentspaceng.netlify.app](https://studentspaceng.netlify.app/)

## ✨ Upcoming/Key Features

* **Aggregate Calculator & Eligibility Checker:** Takes UTME and Post-UTME performance metrics to estimate departmental cutoff chances.
* **Dynamic Theme Engine:** Custom CSS styling allowing users to toggle between different visual modes.
* **Interactive Utilities:** Built-in mini-games and tools to keep prospective students engaged.
* **Responsive Architecture:** Optimized for both mobile and desktop viewports.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (DOM manipulation)
* **Deployment & Hosting:** Netlify
* **Version Control:** Git & GitHub
